# creator-experience

**Labels:** `Content` `Stream` · **Setup:** [manual](setup/manual.md) · [automated](setup/automated.md) (partial)

Creator Experience layer (Roadmap §1). OBS + scenes + multi-platform streaming + broadcast control.

Stream Extend's managed **Go Live + Record** control starts local OBS recording before streaming.
Stopping the managed session finalizes the recording and registers its existing path in Creator
Extend's shared recording inbox. A stream started directly in OBS remains operator-owned.
