## Default Permission

Inspect the bundled catalog and read-only audio routing-tool/reference evidence; detect/bootstrap Python, FFmpeg, OBS and Docker Desktop; launch detected desktop apps; preview the bundled OBS scene and Docker service plans; save module and scanned capture-device choices; run local dependency/capture checks; start and initialize selected allowlisted Docker services; copy only named generated local credentials; install selected catalog requirements; and read installation progress. No arbitrary command or path execution.

#### This default permission set includes the following:

- `allow-audio-setup-status`
- `allow-snapshot`
- `allow-python-status`
- `allow-start-python-bootstrap`
- `allow-ffmpeg-status`
- `allow-start-ffmpeg-bootstrap`
- `allow-obs-status`
- `allow-start-obs-bootstrap`
- `allow-launch-obs`
- `allow-obs-scene-plan`
- `allow-docker-status`
- `allow-docker-plan`
- `allow-start-docker-bootstrap`
- `allow-launch-docker-desktop`
- `allow-start-docker-services`
- `allow-start-local-service-bootstrap`
- `allow-copy-local-credential`
- `allow-save-selection`
- `allow-manual`
- `allow-check`
- `allow-capture-scan`
- `allow-capture-test`
- `allow-save-capture-selection`
- `allow-start-install`
- `allow-job-status`
