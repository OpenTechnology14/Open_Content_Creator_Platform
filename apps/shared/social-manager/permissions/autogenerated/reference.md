## Default Permission

Read the bundled social profile/logo catalog, persist validated active profile/account routing, start the fixed loopback account service, begin catalog-scoped OAuth, and read redacted connections. No arbitrary command, URL, or path execution.

#### This default permission set includes the following:

- `allow-snapshot`
- `allow-selection`
- `allow-activate-profile`
- `allow-save-selection`
- `allow-start`
- `allow-status`
- `allow-authorize`
- `allow-connections`
- `allow-disconnect`
