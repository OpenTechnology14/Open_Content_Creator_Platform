# Public source edition

Open Content Creator Platform is a pre-release source preview. This repository starts with fresh history: no prior development PRs, issues, Actions logs, account matrix or private operating records are copied. Historical development evidence described in the docs is not a public PR archive or evidence that this repository ran those checks.

The source includes the social channel/concept controls and account setup guides. Native/provider acceptance and production-release gates remain open. No installers, model weights or credentials are distributed. Existing app IDs and local data paths retain their compatibility names; the product is Open Content Creator Platform.

Keep local accounts and secrets outside Git. Use the account setup template with a private inventory and password-manager references. See scripts/release/README.md for the reviewed snapshot process and README.md for setup and license boundaries.
