6 Audio Production + Routing
Bus Architecture 
| Bus      | Sources               | Destination          |
|----------|-----------------------|----------------------|
| MIC      | Microphone            | Stream, Call         |
| GAME     | Desktop audio         | Stream, Headphones   |
| MUSIC    | Background music      | Stream, Headphones   |
| AI-VOICE | TTS / AI agents       | Stream, Headphones   |
| CALL-IN  | Discord / Zoom        | Headphones, Stream   |
| MONITOR  | What YOU hear         | Headphones only      |
VoiceMeeter Potato Layout 
# Hardware Inputs
HW1: Mic (interface input)

# Virtual Inputs
VIN1: Desktop → Windows default playback = "VoiceMeeter Input"
VIN2: AI/TTS → AI app output = "VoiceMeeter AUX Input"
VIN3: Call   → Discord output = "VoiceMeeter VAIO3 Input"

# Hardware Outputs
A1: Headphones (interface output)

# Virtual Outputs
B1: → OBS (capture "VoiceMeeter Output" as desktop audio)
B2: → Discord mic-in (mix-minus: no echo)

# Routing per channel:
Mic:     A1 ✓  B1 ✓  B2 ✓
Desktop: A1 ✓  B1 ✓  B2 ✗
AI:      A1 ✓  B1 ✓  B2 ✗
Call:    A1 ✓  B1 ✓  B2 ✗ (no echo)
Mic Processing Chain 
1. High-pass filter: 80 Hz
2. Gate: open -32 dB, close -36 dB, 50ms attack, 200ms release
3. De-esser (optional): 6-8 kHz
4. Compressor: 4:1 ratio, threshold -18 dB, 10ms atk, 100ms rel
5. EQ: broadband corrective
6. Limiter: -1 dB ceiling
