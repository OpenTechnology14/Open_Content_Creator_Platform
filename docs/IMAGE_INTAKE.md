# Image Intake

> **Status:** Reference · **Last reviewed:** 2026-09-02 · **Owner:** OpenTechnology14

How photographs enter the platform, become a training corpus, and stay legally distributable.

**Who this is for:** anyone feeding their own pictures into
[`nature-generation`](../modules/nature-generation/README.md) or
[`cityscape-generation`](../modules/cityscape-generation/README.md). Both modules consume corpora
built by this process; neither duplicates it.

**Why it is one shared doc:** intake is identical for both modules — the same buckets, the same
provenance record, the same rights rules. What differs is *curation*, and each module's
`corpus/README.md` covers its own criteria. Read this first, then that.

---

## 1. Mapping matrix — which module takes this photo?

The first decision, and the one people get wrong most often.

| What the photo mostly shows | Module | Why |
|---|---|---|
| Terrain, forest, water, sky, weather, wilderness | **nature** | Organic geometry; small structural error reads as natural variation |
| Skyline, street, building facade, interior architecture | **cityscape** | Hard geometry; straight lines and window grids fail visibly |
| A city park with no buildings in frame | **nature** | Judge by what is *in frame*, not where you stood |
| A distant town in a valley, landscape-dominant | **nature** | The buildings are texture at that scale, not structure |
| Beach with a pier, coastline with a lighthouse | **split — see below** | Contains a hard-geometry subject |
| Mountains behind a city skyline | **cityscape** | The failure mode that matters is the skyline |
| People as the subject | **neither** | Out of scope for both. See §5 |

### The mixed-scene rule

**Route by failure mode, not by subject count.** If the frame contains anything with hard
straight lines that a viewer would notice bending — a pier, a bridge, a building edge, a road
marking — it belongs in the cityscape corpus even if 80% of the pixels are landscape. The
cityscape module's lineart conditioning exists precisely for that, and the nature module has none.

When genuinely torn, prefer **cityscape**: over-conditioning a nature scene costs a little
inference time, while under-conditioning a structural scene produces visibly bent output.

## 2. Mapping matrix — source to rights

`rights` in the manifest is the field that decides whether an image can train anything.

| Where it came from | `source` | `rights` | Training-eligible? |
|---|---|---|---|
| Your camera, your shot | `own-camera` | `owned` | **yes** |
| Your phone | `own-phone` | `owned` | **yes** |
| Bought from a stock library | `stock` | `licensed` | **only if the license permits ML training** — most do not |
| Creative Commons, attribution required | `cc` | `cc-by` | yes, and attribution must survive into anything you ship |
| Public domain / CC0 | `public-domain` | `public-domain` | **yes** |
| A client paid you to shoot it | `client-work` | *check the contract* | usually **no** — the client often owns it |
| Found online, source unknown | — | — | **no.** Never |
| AI-generated by someone else | — | — | **no.** Provenance is unknowable |

> **Stock licenses are the trap.** "I paid for it" is not the same as "I may train on it". Most
> stock licenses grant use in a work product, not use as training data. Read the actual clause
> before setting `licensed`.

An image whose rights you cannot state is not a borderline case — it is excluded. You cannot
retro-fit the answer once you have forgotten where a file came from, and one unclear image makes
the adapter trained on it unclear, because the weights do not separate.

## 3. Mapping matrix — format to what you can do with it

Intake format constrains which operations are honest later.

| Format | Bit depth | Highlight recovery | Heavy grading | Training |
|---|---|---|---|---|
| RAW (CR3, NEF, ARW, DNG) | 12–14 | **yes** | yes | Convert to 16-bit TIFF first |
| TIFF 16-bit | 16 | yes | yes | **best** |
| PNG 16-bit | 16 | limited | yes | good |
| JPEG (quality 90+) | 8 | **no** | limited | acceptable |
| JPEG (quality <80) | 8 | no | **no** | avoid — compression artefacts get learned |
| HEIC | 8–10 | limited | limited | convert first |
| Screenshot / re-save of a re-save | 8 | no | no | **no** |

**Keep the highest-bit-depth original in `raw/`.** Clipped highlights in an 8-bit JPEG are not
recoverable — the values are gone, and no tier of either module invents them back correctly.
Grade from the original and export 8-bit at the end, never the reverse.

## 4. Manual setup — the intake steps

### Step 1 — create the buckets

```bash
mc mb local/nature-corpus
mc mb local/cityscape-corpus
```

MinIO must be running — `make up`, see
[storage-data](../modules/storage-data/setup/automated.md). Both buckets (`nature-corpus`,
`cityscape-corpus`) are already in `scripts/setup/minio_init.sh`'s `BUCKETS` array, so `make up`
creates them — the `mc mb` commands above are only needed if you're adding them to an
already-running MinIO by hand.

### Step 2 — upload to `raw/`

```
<domain>-corpus/
├── raw/                as ingested, never modified, never deleted
├── curated/            passed review, training-eligible
└── manifest.jsonl      one provenance record per image
```

`raw/` is append-only. Curation is a *selection*; a training run whose inputs were pruned cannot
be reproduced, and that is the single most expensive mistake available here.

### Step 3 — write a provenance record

One JSON object per line in `manifest.jsonl`, for **every** image:

```json
{
  "id": "nat-000431",
  "file": "raw/nat-000431.dng",
  "sha256": "…",
  "captured": "2026-07-14",
  "source": "own-camera",
  "rights": "owned",
  "license": null,
  "people_present": false,
  "location_consent": true,
  "notes": "north ridge, overcast, 14mm"
}
```

| Field | Why it is required |
|---|---|
| `sha256` | The only reliable way to tell whether a training set changed |
| `source` / `rights` | Decides training eligibility — see §2 |
| `license` | The actual license text or URL whenever `rights` is not `owned` |
| `people_present` | Recognisable people carry constraints a crop does not remove |
| `location_consent` | Private property, interiors, and some landmarks are restricted |

**An image with no manifest line is not training-eligible.** Not flagged — excluded.

### Step 4 — curate into `curated/`

Module-specific criteria:
[nature](../modules/nature-generation/corpus/README.md) ·
[cityscape](../modules/cityscape-generation/corpus/README.md).

### Step 5 — pin the set

When you train, record the manifest's own `sha256` in the adapter's training config. Without it,
"which images produced this adapter" is unanswerable within weeks, and a re-train that quietly
used a different corpus is indistinguishable from one that did not.

## 5. People, plates, and private property

Neither module is for photographing people, but people appear in real photographs.

| Situation | Do |
|---|---|
| Recognisable face in frame | Crop it out, or set `people_present: true` and exclude from training |
| Crowd, no individual identifiable | Usually fine; record it |
| Readable license plate | Crop or blur before `curated/` |
| Private property interior | Needs the owner's consent; record in `location_consent` |
| Restricted landmark | Some have image restrictions — check before commercial use |

The same principle governs face swap in
[`realtime-ai`](../modules/realtime-ai/README.md): you only train on likenesses you hold rights
to. A landscape crop does not launder an image of a person.

## 6. Tips

**Corpus size and variety**

- Under ~30 curated images per domain, an adapter memorises instead of generalising.
- 80 varied images beat 300 near-identical ones. Forty shots of one ridge in one light teach the
  model *that ridge*, not "nature".
- Vary time of day, weather, season, and focal length deliberately.

**What to reject at curation**

| Reject | Because |
|---|---|
| Motion blur, heavy noise | The adapter learns the artefact, not the scene |
| Heavy existing grade | You are training on someone else's look |
| Near-duplicates (burst frames) | Over-weights whatever they depict |
| Watermarks, burned-in text or date stamps | Reproduced by the model, visibly |
| Anything you would not show a client | The model will average it in |

**Practical**

- Ingest in batches by shoot, not one at a time — provenance is easier to get right while you
  still remember the shoot.
- Compute `sha256` at upload; retro-fitting hashes across thousands of files is miserable.
- Keep `notes` honest and specific. "north ridge, overcast, 14mm" is worth more later than "nice".
- Name by domain prefix (`nat-`, `cty-`) so a misfiled image is visible in a listing.

**What not to do**

- Do not delete from `raw/` to save space. Push cold originals to cheaper storage instead.
- Do not mix domains in one bucket "temporarily". It never gets unmixed.
- Do not start training before curation. A bad corpus produces a bad adapter in three hours, and
  you learn nothing about why.

## 7. Mapping matrix — what you want, to which tier

Both modules share this ladder. The rule: **route to the cheapest tier that does the job.**

| You want | Tier | Needs a corpus? | Needs a GPU? |
|---|---|---|---|
| More saturated, brighter, warmer | **0** | no | **no** |
| Straighten converging verticals | **0** (cityscape) | no | **no** |
| Make this photo look like that one | 1 | reference image only | yes |
| Replace the sky | 2 | no | yes |
| Widen the frame | 2 | no | yes |
| A new scene in my style | 3 | trained adapter | yes |
| Learn my style | 4 | curated corpus | yes, hours |

Tier 0 needs nothing from this guide — no corpus, no rights research, no GPU. If tone work is all
you want, skip intake entirely and go straight to the module's `grading/`.
